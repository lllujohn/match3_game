# 星空消消乐 (Match-3 Game)

本项目为程序设计课程实践作品——基于 C 语言和 SDL2 库开发的消消乐游戏。
游戏实现了基础的消除逻辑、流畅的动画特效，并加入了一些有趣实用的道具机制。整个架构严格遵循 MVC 模式，将核心算法与界面渲染彻底分离。

## 开发环境
- **语言**：C11
- **图形库**：SDL2, SDL2_image, SDL2_ttf, SDL2_mixer
- **构建工具**：CMake (3.15+)
- **支持平台**：macOS / Linux / Windows

## 功能特点
- **基础玩法**：经典的交换消除机制，连续消除可触发高倍连击加分。
- **动态特效**：使用指数级阻尼缓动（Exponential Easing）算法，实现了平滑的宝石交换、掉落以及缩放消除动画。
- **道具系统**：
  - **小木槌**：精准砸碎并消除指定的单个宝石。
  - **魔法棒**：无视规则，强制交换任意两个宝石。
  - **星空重置**：打乱当前棋盘上的所有宝石，拯救死局。
  - **时光沙漏**：为当前关卡增加额外的步数。
- **视听体验**：绘制了定制化的星空背景，所有的操作和道具均匹配了专属的高级音效，UI文字渲染带有提升清晰度的投影效果。
- **进度保存**：支持一键快速保存（S）与读取（L）当前的游戏状态。

## 编译运行
本项目使用 CMake 进行构建。请确保您的系统已安装 SDL2 及其相关扩展库。

```bash
mkdir build
cd build
cmake ..
make
./match3_game
```

## 操作说明
- **鼠标左键**：点击选中并交换相邻的宝石，或者在右侧信息栏点击使用道具。
- **U 键**：撤销上一步操作。
- **R 键**：重新开始当前关卡。
- **S 键**：保存当前游戏进度。
- **L 键**：读取上次保存的进度。
- **P 键**：暂停 / 继续游戏。
- **ESC 键**：退出游戏。

## 项目结构
- `src/model.c`: 纯粹的 C11 游戏核心逻辑，包含棋盘状态更新、消除算法、道具处理等（零外部 UI 依赖）。
- `src/view.c`: 负责 SDL2 图像、文字的渲染，动画的插值计算以及音效播放。
- `src/controller.c`: 负责处理键盘与鼠标的输入事件，并控制游戏状态机的流转。
- `include/`: 存放所有的头文件、常量定义与公共数据结构。
- `assets/`: 存放游戏运行所需的图片、音效以及字体资源。
