# 星空消消乐

这是我的程序设计课程实践大作业——一个基于 C 语言和 SDL2 开发的星空消消乐游戏。

## 游戏介绍
主要实现了经典的消消乐玩法，包含消除、掉落动画，还有几种可以使用的特殊道具。

- **基础玩法**：经典的交换消除，连续消除有连击加分。
- **道具系统**：
  - **小木槌**：直接砸碎指定的一个宝石。
  - **魔法棒**：强制交换任意两个宝石。
  - **星空重置**：打乱棋盘，用来拯救死局。
  - **时光沙漏**：增加当前关卡的剩余步数。
- **进度保存**：支持一键保存（S）与读取（L）当前进度。

## 编译运行
本项目使用 CMake 构建，需要提前装好 SDL2 及相关扩展库（sdl2_image, sdl2_ttf, sdl2_mixer）。

```bash
mkdir build
cd build
cmake ..
make
./match3_game
```

## 操作说明
- **鼠标左键**：点击选中并交换相邻的宝石，或者在右侧信息栏点击使用道具。
- **R 键**：重新开始当前关卡。
- **S 键**：保存进度。
- **L 键**：读取进度。
- **P 键**：暂停 / 继续游戏。
- **ESC 键**：退出游戏。

## 目录结构
- `src/`：所有的 C 源码文件。
- `include/`：头文件定义。
- `assets/`：游戏用到的图片、音效和字体。
